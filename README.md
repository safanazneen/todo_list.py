# Python To-Do List Application

## Project Overview

The **Python To-Do List Application** is a simple, interactive, command-line project developed using Python to help users organize and manage their daily tasks efficiently. The application allows users to add new tasks, display their task list, mark tasks as completed, and delete tasks that are no longer needed.

The main objective of this project is to develop a basic task management system while understanding important Python programming concepts. It provides a menu-driven interface that allows users to select different operations by entering a number. The project is suitable for beginners who want to improve their programming skills through practical application development.

## Features

- **Add Tasks:** Users can enter new tasks and add them to their to-do list.
- **Display Tasks:** Displays all available tasks with their current status.
- **Mark as Completed:** Allows users to mark individual tasks as completed.
- **Delete Tasks:** Removes selected tasks from the list.
- **Input Validation:** Handles empty task names, invalid choices, and incorrect task numbers.
- **Interactive Menu:** Provides a simple menu for navigating between different operations.

## Technologies Used

- **Programming Language:** Python 3
- **Data Structures:** Lists and dictionaries
- **Concepts:** Functions, loops, conditional statements, user input, and exception-free input validation.

## How It Works

When the application starts, it displays a menu containing five options. Users can choose to add a task, display existing tasks, mark a task as completed, delete a task, or exit the application. The program processes each selection and displays an appropriate message. Tasks are stored in memory while the application is running.

## Learning Outcomes

This project helps develop logical thinking, problem-solving abilities, and an understanding of Python functions, lists, dictionaries, loops, and conditional statements.
